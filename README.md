# CCNA Labs

Cisco Packet Tracer labs from working through Jeremy's IT Lab CCNA 200-301 course.

## Structure

All labs are kept in one folder, `Jeremys LABS/`, as individual Packet Tracer files named `Day XX Lab - Topic.pkt`, numbered by course day.

## Topics covered so far

- Packet Tracer Introduction
- Connecting Devices
- OSI Model
- Basic Device Security
- Ethernet LAN Switching
- IPv4 Addresses
- Interface Configuration
- Configuring Static Routes
- Troubleshooting Static Routes
- Life of a Packet
- VLSM

## Tools

- Cisco Packet Tracer

## Status

Work in progress, updated as new labs are completed.
